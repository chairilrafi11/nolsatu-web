# Latihan

Folder untuk **menulis jawaban latihan** tiap bab. Satu folder per bab.

## Cara pakai

1. Baca materi bab di `bab/`
2. Kerjakan latihannya di folder `latihan/bab-XX/` yang sesuai
3. Tiap folder sudah ada `Main.java` kosong — tulis jawabanmu di sana
4. Run di VS Code (tombol ▶ atau Ctrl+Alt+N)

## Aturan

- Kalau jawabanmu lebih dari satu file (misal bab 10 butuh class `Hero`), boleh tambah file baru di folder yang sama
- Simpan semua di folder, jangan nulis jawaban langsung di file materi `bab/`
