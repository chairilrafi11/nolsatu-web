# Belajar Java untuk Pemula (Mobile Legends Edition)

Selamat datang! Course ini buat kamu yang **belum pernah ngoding sama sekali**.
Kita belajar Java pelan-pelan, dengan analogi game **Mobile Legends** biar gampang nempel di otak.

## Cara pakai

1. Buka bab dari `bab/` sesuai urutan. **Jangan loncat** — tiap bab butuh bab sebelumnya.
2. Baca bagian analogi dulu (pembuka), baru materi.
3. Ketik sendiri contoh kodenya, jangan cuma copy-paste. Otot nulis = otot ngoding.
4. Kerjakan latihan di akhir bab **sebelum** buka kunci jawaban. Tulis jawabanmu di folder `latihan/bab-XX/` yang sesuai (tiap bab sudah ada `Main.java` kosong).
5. Kunci jawaban ada di dalam blok tersembunyi (klik untuk buka). Jujur ya, jangan buka duluan.

## Persiapan

Kamu sudah punya:
- ✅ Java (JDK) terinstall
- ✅ VS Code
- ✅ Extension **Code Runner** (biar bisa run langsung dengan tombol ▶ atau Ctrl+Alt+N)

Kalau belum kebaca, buka bab `03-hello-world` — di sana ada cara bikin & run file pertama.
