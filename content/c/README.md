# Belajar C untuk Pemula

Lanjutan setelah Java. Di sini kamu melihat langsung bagaimana komputer bekerja: memori, tipe data,
dan compiler — tanpa lapisan yang menyembunyikan.

## Cara pakai

1. Baca bab dari `bab/` sesuai urutan. Jangan loncat.
2. Ketik sendiri contohnya di VS Code, jangan copy-paste.
3. Compile dan jalankan di terminal:

```bash
gcc main.c -o main
./main
```

4. Kerjakan latihan, lalu kirim hasilnya lewat halaman latihan di NolSatu.

## Daftar Isi

| Bab | Judul | Isi |
|-----|-------|-----|
| 01 | Kenalan dengan C | program pertama, compile, titik koma |
| 02 | Variabel & Tipe Data | int, float, double, char, printf |
| 03 | Input & Output | scanf, fgets, jebakan input |
| 04 | Percabangan | if, else if, switch |
| 05 | Perulangan | for, while, do-while, break, continue |
| 06 | Array | index, ukuran, bahaya keluar batas |

## Aturan main

- C tidak memaafkan tebakan. Baca pesan compiler, jangan menebak.
- Error itu normal. Yang penting kamu tahu cara membacanya.
- Satu bab = satu konsep. Paham benar baru lanjut.
