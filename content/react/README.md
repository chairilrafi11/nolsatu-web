# Belajar React + Vite (Dashboard CRUD Mahasiswa)

Lanjutan dari course Java. Kali ini kita masuk ke **frontend modern** — bikin aplikasi web pakai **React**, **Vite**, **TypeScript**, dan **Tailwind CSS**.

Hasil akhir: **dashboard manajemen data mahasiswa** (tambah, lihat, edit, hapus) — persis aplikasi yang dipakai admin kampus. Dari sini nanti bisa berkembang ke API beneran.

## Cara pakai

1. Buka bab dari `bab/` sesuai urutan. Jangan loncat.
2. Bab 01 → ikuti **setup** bikin projek Vite. Setelah itu projek yang sama dipakai terus, dibangun bertahap.
3. Tiap bab: baca analogi → materi → contoh kode → **ketik sendiri**, bukan copy-paste.
4. Kerjakan latihan di `latihan/bab-XX/` sebelum lihat kunci.

## Stack yang dipakai

- **React** — library UI, bikin tampilan dari komponen
- **Vite** — tool yang menjalankan & mengemas projek (super cepat)
- **TypeScript** — JavaScript + tipe data (nyambung konsep tipe dari course Java!)
- **Tailwind** — styling cepat dengan class di HTML
